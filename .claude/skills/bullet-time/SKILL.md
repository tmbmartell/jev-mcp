# BULLET TIME

**Use em:** abertura de Reels, produto voando, momento de impacto.

## O que é
O tempo **congela completamente** no auge da ação (sujeito no ar, gotas/partículas suspensas) enquanto a câmera faz uma **órbita suave** ao redor. Depois o tempo volta devagar. Um único plano contínuo, sem cortes.

## Prompt base (referência)
```
Bullet time effect: time freezes completely with the man suspended mid-air and every water droplet frozen, while the camera makes a smooth 180-degree orbit around him. Then time slowly resumes. One continuous cinematic shot, no cuts.
```

## Template
```
Bullet time effect: time freezes completely with {SUJEITO} suspended mid-air and every {PARTÍCULAS} frozen, while the camera makes a smooth {GRAUS}-degree orbit around {PRONOME_OBJ}. Then time slowly resumes. One continuous cinematic shot, no cuts.
```

## Variáveis
- **SUJEITO**: the man, the dancer, the skateboarder, the perfume bottle, the sneaker...
- **PARTÍCULAS**: water droplet, glass shard, confetti piece, sand grain, coffee splash...
- **GRAUS**: 90, 180, 360.
- **Extra (produto)**: `studio lighting, clean background` para anúncios.

## Como responder
1. Defina o sujeito (pessoa ou produto) e o que fica suspenso no ar.
2. Entregue o prompt final **em inglês**, num bloco de código.
3. Ofereça uma variação (ex.: versão produto para Reels).
4. Mantenha as palavras-chave: `Bullet time effect`, `time freezes completely`, `suspended mid-air`, `smooth orbit`, `time slowly resumes`, `one continuous shot, no cuts`.
