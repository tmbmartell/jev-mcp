# MINIATURA

**Use em:** vídeo de cidade, viagem ou evento visto de cima.

## O que é
Efeito **tilt-shift**: desfoque seletivo + vista do alto + movimento acelerado fazem o mundo real parecer uma **maquete em escala**, com pessoas e veículos como brinquedos e sensação de stop-motion.

## Prompt base (referência)
```
Tilt-shift miniature time-lapse: tiny boats move fast across the turquoise water and tiny people walk on the beach like toys in a scale model. Static camera from above, stop-motion feel, bright sunny day.
```

## Template
```
Tilt-shift miniature time-lapse: tiny {ELEMENTO_1} {MOVIMENTO_1} across {CENÁRIO_1} and tiny {ELEMENTO_2} {MOVIMENTO_2} {CENÁRIO_2} like toys in a scale model. Static camera from above, stop-motion feel, {CLIMA}.
```

## Variáveis
- **ELEMENTO**: boats, cars, buses, people, trains, bikes...
- **MOVIMENTO**: move fast, zip, stream, walk, dance...
- **CENÁRIO**: turquoise water, busy avenue, city square, stadium, festival grounds...
- **CLIMA**: bright sunny day, golden hour, colorful saturated tones...

## Como responder
1. Descubra o lugar/evento e o que se move nele.
2. Entregue o prompt final **em inglês**, num bloco de código.
3. Ofereça uma variação (ex.: versão urbana ou de evento).
4. Mantenha as palavras-chave: `tilt-shift miniature`, `tiny`, `like toys in a scale model`, `static camera from above`, `stop-motion feel`. Cores vivas e dia claro reforçam o efeito.
