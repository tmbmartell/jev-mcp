# 📓 Meu Caderno

Um caderno de espiral que roda direto no navegador, sem instalar nada.

**Como usar:** baixe `meu-caderno.html`, guarde numa pasta fixa (ex.: Documentos) e abra com Chrome ou Edge.
Tudo que você escreve fica salvo **neste computador e neste navegador**.

- **Virar página:** setas ‹ › nas laterais ou Alt+← / Alt+→ (na última página, o ＋ cria uma nova)
- **Texto:** é só clicar e escrever. Tem negrito, cores de caneta, marca-texto, listas e caixinhas ☐
- **Link:** botão 🔗 (no texto ou como bilhetinho), ou cole uma URL com Ctrl+V. Para abrir um link do texto, use Ctrl+clique
- **Imagem:** botão 🖼️, Ctrl+V de um print ou arraste o arquivo para a página
- **Figurinhas:** botão ⭐. Depois de colar, você pode arrastar, girar (⟳), mudar o tamanho (↘) e tirar (✕)
- **Backup:** 💾 baixa uma cópia `.json`; 📂 restaura uma cópia

Dica: no Chrome, abra o arquivo e use ⋮ → Transmitir, salvar e compartilhar → Criar atalho → "Abrir como janela" para ele virar um app.
